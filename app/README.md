# Music-Led-2.0 App

Proyecto Flutter para controlar la tira LED vía Bluetooth, replicando el diseño y funcionalidades de la interfaz web original.

## Estructura inicial
- lib/: Código fuente principal de Flutter
- android/, ios/, web/: Plataformas soportadas
- pubspec.yaml: Dependencias y configuración

## Próximos pasos
- Implementar UI basada en el diseño web
- Agregar soporte para Bluetooth (flutter_blue)
- Conectar con ESP32 para control de LEDs
