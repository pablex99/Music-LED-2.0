# Music-Led-2.0

Nueva versión del controlador de tira LED basado en ESP32, con comunicación Bluetooth para control desde una app móvil dedicada.

## Objetivo
Migrar el control de la tira LED de WiFi/Web a Bluetooth/App, manteniendo el diseño y funcionalidades para facilitar la venta del producto.

## Estructura inicial
- src/: Código fuente principal
- include/: Archivos de cabecera
- lib/: Librerías externas o propias
- data/: Recursos adicionales (si aplica)
- test/: Pruebas
